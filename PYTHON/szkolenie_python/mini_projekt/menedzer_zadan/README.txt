MENEDŻER ZADAŃ

Uruchomienie programu:

macOS / Linux:
1. Otwórz terminal w folderze projektu.
2. Aktywuj środowisko:
   source venv/bin/activate
3. Uruchom program:
   python main.py

Windows:
1. Otwórz terminal w folderze projektu.
2. Aktywuj środowisko:
   venv\Scripts\activate
3. Uruchom program:
   python main.py
